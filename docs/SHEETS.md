# Интеграция с Google Sheets

Цель — дать админу прозрачную аналитику без отдельного интерфейса (ТЗ §9).

## Подготовка

1. Создать **Service Account** в Google Cloud Console.
2. Скачать JSON-ключ → положить в `secrets/google-sa.json`.
3. Создать пустой Google Spreadsheet, скопировать `Sheet ID` из URL.
4. **Расшарить** таблицу на email service-account'а с правами Editor.
5. В `.env`:
   ```
   GOOGLE_SA_JSON_PATH=/run/secrets/google-sa.json
   GOOGLE_SHEET_ID=1AbCdEf...
   ```

## Структура листов

Бот ожидает 4 листа с **точно** такими именами:

### `Applicants`

| ID | Имя | Возраст | Город | Должность | Опыт | Зарплата | График | Контакт | Статус | Дата |
|----|-----|---------|-------|-----------|------|----------|--------|---------|--------|------|

### `Employers`

| ID | Компания | Город | Контакт | Телефон | Дата |
|----|----------|-------|---------|---------|------|

### `Vacancies`

| ID | Компания | Должность | Зарплата | График | Адрес | Требования | Статус | Дата |
|----|----------|-----------|----------|--------|-------|------------|--------|------|

### `Interviews`

| ID | Кандидат | Вакансия | Компания | Дата | Время | Статус |
|----|----------|----------|----------|------|-------|--------|

## Маппинг событий → строки

| Событие | Лист | Действие |
|---|---|---|
| Создана анкета | Applicants | append_row |
| Обновлена анкета | Applicants | update_row (по ID) |
| Изменён статус кандидата | Applicants | update_cell(status) |
| Создана вакансия | Vacancies | append_row |
| Изменён статус вакансии | Vacancies | update_cell(status) |
| Назначено собеседование | Interviews | append_row |
| Статус собеседования | Interviews | update_cell(status) |
| Создан Employer | Employers | append_row |

## Авто-поля аналитики (ТЗ §9.5)

В шапке листа `Applicants` (например, в J1:M1) добавить формулы:

- `=COUNTA(B:B)-1` — всего кандидатов
- `=COUNTIF(K:K, "Новый")` — новых
- `=COUNTIF(K:K, "Прошёл собеседование")` — прошли собес
- На отдельном листе `Stats`:
  - `=COUNTIFS(Applicants!L:L, ">="&TODAY())` — за сегодня
  - Конверсия анкета→собес: `=COUNTIF(Interviews!A:A, "<>")/COUNTA(Applicants!A:A)`

## Rate limits

Google Sheets API: **100 запросов / 100 сек / user**. Стратегии:

1. Использовать `values_batch_update` для пачек.
2. Буфер на 5 сек в `GoogleSheetsService` — собираем события в очередь, отправляем пачкой.
3. На retry — exponential backoff с jitter.

## Защита от сбоев

Все вызовы Sheets обёрнуты в `try/except` (см. `app/services/google_sheets.py`). Если Google упал — событие логируется как `sheets_*_failed`, но **сценарий пользователя не ломается**. Восстановление — отдельным джобом «sync_missing_rows», читающим из БД то, чего нет в листах.
